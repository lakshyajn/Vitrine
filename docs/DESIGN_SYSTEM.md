# Frontend Design System

## Intent
A considered trade workspace for independent makers finding appropriate retail partners: editorial typography, precise information hierarchy, restrained craft references and high-quality B2B information design. Avoid generic AI-dashboard templates. The textile workshop is a demo scenario only; keep the product category- and country-agnostic.

## Visual direction
- Canvas: warm paper/off-white, deep ink text, quiet neutral dividers.
- Primary accent: forest/pine green. Use clay/terracotta and ochre sparingly.
- Typography: readable sans for controls/body; editorial serif only for select titles or story moments.
- Layout: desktop sidebar, clear title/action row; mobile reflows to one column with drawer/bottom nav.
- Density: generous forms, practical compact tables. Do not put every section in a card.
- Images: purposeful product/material imagery only if useful; avoid stock hero banners and randomly mixed images.
- Motion: subtle transitions; honour `prefers-reduced-motion`.

## Composition
One dominant title and one primary action per page. Use type, alignment and spacing before containers. Forms have labels, hints, units and field errors. Tables have clear headers, visible filter state and empty/loading/error states. Keep verified evidence, AI assessment, unknowns, demo data and taste/market hypotheses visually separate. Null is an explicit state, not zero.

## Avoid
Purple/blue gradients, glassmorphism, neon, floating blobs, excessive shadows, repeated card grids, fake charts/statistics/logos/retailer URLs, generic “AI-powered” slogans and excessive badges. Don't polish dashboard before discovery and leads.

## Accessibility
Semantic landmarks/headings, explicit labels, correct button types, keyboard-visible focus, accessible dialogs, descriptive links, useful alt text and reduced motion. Test mobile/tablet/desktop, keyboard-only navigation and contrast.
